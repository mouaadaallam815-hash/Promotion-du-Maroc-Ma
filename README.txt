Promotion du Maroc — version nouvelle
Fichiers : index.html, logo.png, manifest.json, sw.js.
Déploiement GitHub Pages :
1. Décompressez le ZIP.
2. Dans votre nouveau dépôt GitHub, utilisez Add file > Upload files.
3. Téléversez les 4 fichiers à la racine du dépôt puis Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Ouvrez l'URL GitHub Pages après la fin du déploiement.
Les liens des entreprises ouvrent leurs sites officiels. Les prix de carburant peuvent être saisis manuellement et restent stockés sur l'appareil qui les a saisis ; ils ne sont pas partagés entre utilisateurs.
